# Logos des moyens de paiement
Logos officiels affichés pour identifier les moyens de paiement acceptés (marques de leurs propriétaires).
- `ORANGE_MONEY.svg` : logo Orange Money (Wikimedia Commons, « Logo Orange Money.svg »)
- `WAVE.png` : logo Wave (site officiel wave.com)

Pour un autre moyen de paiement : déposer le fichier ici et l'ajouter dans `OFFICIAL` de
`src/presentation/components/ui/PaymentLogo.tsx`.
